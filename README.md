# ПитЛайн — веб-сервис для шиномонтажа

Запись → автомобиль → пост → мастер → работа → статус → оплата → история → повторная запись.

## Запуск

Сборка не нужна. Любой из вариантов:

- открыть `index.html` двойным кликом;
- или запустить локальный сервер: `node serve.js` → http://localhost:5173

Нужен интернет только для шрифта Manrope и Three.js (3D-колесо). Без них всё работает, колесо просто не показывается.

## Три интерфейса

| Адрес | Для кого | Что внутри |
|---|---|---|
| `#/` | Клиент (телефон) | Главная, запись в 5 шагов, записи со статусом, автомобили, история, профиль, калькулятор |
| `#/admin` | Владелец / администратор (компьютер) | Обзор, записи, клиенты, автомобили, мастера, услуги и цены, склад, календарь постов, оплаты, настройки |
| `#/master` | Мастер на посту | Текущая работа, кнопка «Следующий этап», очередь на день |

Откройте клиента и админку в двух вкладках: смена статуса в кабинете или на экране мастера сразу появляется у клиента (уведомление и обновлённый трекер).

## День и ночь

- Кнопка с солнцем / луной в шапке каждого экрана: новая тема раскрывается кругом из точки нажатия (View Transitions API; в браузерах без него цвета плавно перетекают).
- В профиле клиента и в «Настройки» кабинета — выбор «День / Ночь / Авто» («Авто» следует системной теме телефона или компьютера).
- На фоне — анимированная разметка пит-лейна и световые следы машин; ночью это фары, стоп-сигналы и мерцающие огоньки. Есть параллакс при прокрутке, анимация ставится на паузу в фоновой вкладке и отключается при системной настройке «уменьшить движение».

## Демо-режим

- Данные хранятся в `localStorage` браузера; при первом запуске создаются демо-клиенты, автомобили и расписание относительно текущей даты.
- Демо-клиент — Алексей Смирнов. Его текущий заказ сам проходит этапы примерно каждые 15 секунд (выключается в «Настройки → Демо-режим»).
- В демо-режиме расписание пересоздаётся при открытии в новый день, чтобы оставаться актуальным.
- «Сбросить демо-данные» — в профиле клиента или в настройках кабинета.

## Структура

```
index.html
css/app.css      дизайн-система и все экраны
js/util.js       даты, форматирование, иконки, тосты, модальные окна
js/theme.js      дневная / ночная тема и анимация переключения
js/bgfx.js       анимированный фон
js/store.js      данные, расчёт цены, свободное время, статусы, уведомления
js/wheel3d.js    3D-колесо (Three.js): балансировка, прокол, правка диска, смена комплекта
js/client.js     клиентское приложение и калькулятор
js/admin.js      кабинет сервиса
js/master.js     экран мастера
js/app.js        маршрутизация, живые обновления, уведомления
serve.js         локальный сервер для разработки
```

## Что дальше для реального запуска

Сейчас это полностью рабочий фронтенд с локальным хранилищем. Для работы с реальными клиентами нужно заменить `store.js` на API (сервер + база), добавить вход по SMS-коду и отправку уведомлений (SMS / Telegram / push).
